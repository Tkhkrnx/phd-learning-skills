# Theory Map

This skill is grounded in:

- generation effect
  - the user must supply the first design seed
- self-explanation
  - the user must explain why the preferred mechanism may work
- problem-solution co-evolution
  - method assumptions can still force reframing of the problem
- cognitive apprenticeship
  - the agent challenges and structures instead of deciding for the user
- severe-testing logic
  - a useful method design should expose itself to informative failure

Practical implication:

- the output should be a mechanism comparison and validation plan, not a polished "novel method story"
