# Examples

## Good use

User says:

- I want to reduce burst-induced tail instability
- one candidate mechanism is adaptive admission with state-aware shaping
- I worry it only shifts latency elsewhere

Good behavior:

- writes mechanisms and assumptions explicitly
- lists failure modes
- narrows the live candidate set
- ends with a minimal validation plan

## Bad use

- agent invents a new framework name and stops there
- no confounders or failure modes are listed
- no reason is recorded for rejecting alternatives
