# Theory Map

This skill is grounded in:

- generation effect
  - the user must first generate their own account
- self-explanation effect
  - the user must restate the repaired model in their own words
- retrieval practice
  - recall happens before explanation
- illusions of competence
  - completion requires an agent-off restatement or application
- transfer
  - the skill ends only after near or far transfer is checked

Why this matters:

- it prevents passive note consumption
- it keeps the skill scoped to one blocking gap
- it makes the skill useful inside larger research or engineering workflows
