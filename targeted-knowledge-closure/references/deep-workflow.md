# Deep teaching workflow

Use this reference when the initial explanation does not resolve the gap, several prerequisites interact, or the user asks for guided transfer practice.

## Diagnose the smallest gap

Identify whether the blocker is a missing definition, prerequisite, actor/state relation, process sequence, category boundary, or procedure. If the user has no model, orient first; do not test before supplying enough scaffold.

## Choose a representation

- definition for a boundary confusion;
- intuitive model for missing orientation;
- actor-state-operation sequence for process confusion;
- worked example for procedural knowledge;
- contrast or counterexample for category confusion;
- code, equation, or diagram only when it carries the essential relation.

Map analogies back to exact technical objects and state where they fail.

## Repair and transfer

Use the user's question, explanation, prediction, correction, or live-task application as evidence. Replace the specific wrong relation rather than repeating the entire lesson. Once the concept is usable, reduce scaffolding.

When a transfer check is useful, choose one small case from the current task and ask for the consequence and reason. Do not require a ritual quiz if the user has already applied the concept correctly.

## Process integrity

For a process, protocol, timeline, or distributed interaction, make explicit:

- actor or request identity;
- state before the step;
- operation performed;
- whose state or output changes;
- ordering invariant.

Finish when the working model supports the requested application and any remaining gap is unlikely to cause a material error. A delegated teaching subtask returns immediately to its parent goal after that point.
