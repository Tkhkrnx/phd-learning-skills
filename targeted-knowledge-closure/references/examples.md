# Examples

## Good use

User says:

- I think retrieval practice means rereading notes many times
- it blocks my learning workflow design
- I do not understand why recall matters more than review

Good behavior:

- correct "rereading" into active retrieval
- explain intuitive, formal, and task-local versions
- ask the user to restate the concept without cues

## Bad use

- agent gives a broad study-skills lecture
- no transfer case is requested
- no independent restatement is checked
