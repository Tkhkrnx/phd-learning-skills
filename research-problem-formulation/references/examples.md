# Examples

## Good use

User says:

- I suspect long-context serving fails under bursty enterprise workloads
- it matters because tail behavior drives deployment risk
- current work benchmarks smooth synthetic traces

Good behavior:

- expands into a problem card
- separates evidence from inference
- groups prior work into a few buckets
- ends with a next-evidence plan instead of a method

## Bad use

- agent brainstorms solutions immediately
- related work becomes a long unordered bibliography
- no falsification condition is recorded
