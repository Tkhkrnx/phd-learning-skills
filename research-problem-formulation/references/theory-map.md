# Theory Map

This skill is grounded in:

- generation effect
  - the user must supply the first framing
- self-explanation
  - the user must state why the problem matters and what likely fails
- problem-solution co-evolution
  - framing is expected to change as evidence is organized
- cognitive apprenticeship
  - the agent challenges and structures rather than originating the whole direction
- falsification-oriented reasoning
  - the framing should name what evidence would overturn it

Practical implication:

- the output should be a problem definition and evidence plan, not a method pitch
