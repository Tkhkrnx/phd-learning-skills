# Examples

## Good use

User says:

- I think the requirement is to add report export
- the API and UI may both be involved
- I do not know where report data is assembled

Good behavior:

- build an unknowns checklist
- demand code or runtime anchors
- compare 2 to 3 options
- end with one first execution slice

## Bad use

- agent proposes a full architecture before inspecting the system
- no distinction between observed and inferred claims
- no rejection reasons are recorded
