# Theory Map

This skill is grounded in:

- generation effect
  - the user must first state their current understanding
- problem-solution co-evolution
  - task understanding and solution shaping evolve together
- cognitive apprenticeship
  - the agent reviews and scaffolds instead of replacing ownership
- externalized decision rationale
  - the user records why one path is chosen and others are rejected
- explicit design discussion
  - review quality improves when options and assumptions are made concrete

Engineering interpretation:

- clean planning without system evidence is not enough
- repository truth must dominate neat-sounding abstraction
