# 默认模板：BatchGen 论文汇报

## 什么时候使用

按以下顺序选择，不需要用户每次重复给默认模板：

1. 用户本次明确给了新模板或指定了另一套版式：以新要求为准，不混入默认模板的母版、字体和配色。
2. 用户要求继续修改已有 PPT：保留该文件的模板和已完成页面，除非用户明确要求换模板。
3. 新做论文 PPT，且未提供模板：使用本 Skill 的 `assets/batchgen-default.pptx`。

仅作为内容材料提供的 PPT 不自动变成新模板。读取文件失败或新模板损坏时，报告具体问题，不悄悄回退到默认模板。路径均相对当前安装的 Skill 目录，不依赖作者电脑的绝对路径。

可以运行只读选择器：

```text
python scripts/resolve_template.py
python scripts/resolve_template.py --template <用户的新模板.pptx>
python scripts/resolve_template.py --existing-deck <要继续编辑的文件.pptx>
```

若同时指定 `--template` 和 `--existing-deck`，新模板决定目标版式，但选择器仍核验并返回已有稿件；迁移时仍须保护已有内容，不能把它当空白任务重做。

## 这份模板到底是什么

原件由用户指定：`2026-10-9-BatchGen.pptx`，来自 [BatchGen 讨论线程](codex://threads/01a11747-074a-7581-8014-d1042de233ad)。完整 PPT 按字节保留在 `assets/batchgen-default.pptx`，来源与 SHA-256 见 `assets/batchgen-template.json`，封面预览见 `assets/batchgen-preview.png`。

它是**带完整示例内容的参考模板**。复用的是实际母版、主题、页眉与标题位置、字体层次、箭头/项目符号、图文和表格布局，以及讲清论文的深度。不能把 BatchGen 的背景、机制、图表、实验结果或结论带进另一篇论文。

开始时在工作目录建立副本，导入并按角色复用已有页面；不修改安装包或用户原件。保留可编辑文本与表格，不把整页截图当作新幻灯片。

## 如何挑选参考页

| 原稿页码 | 用途 | 新论文中怎么用 |
| --- | --- | --- |
| 1 | 封面 | 替换论文题名、中文题名和会议信息等字段 |
| 2 | 背景与问题 | 使用新论文的背景和陈述句形式的问题 |
| 3 | 重要性与动机 | 放新论文的动机证据，并解释其意义 |
| 4 | 现有工作比较 | 借用类别、代表方法、优势、核心缺陷的可编辑表格布局 |
| 5 | 核心思想与概览 | 替换为新论文的核心思路及原图 |
| 6–12 | 设计、算法与流程 | 选取适合的图文布局，沿新论文自己的设计层次展开 |
| 13 | 实验设置 | 区分硬件/模型、负载/数据、基线、配置与指标 |
| 14–19 | 实验问题与结果 | 借用实验问题标题和图表讲解方式，不照搬问题编号或实验项目 |
| 20 | 总结与启发 | 只写新论文实际支持的结论与可迁移认识 |

这些页码只是**参考页索引**，不是必须按 20 页输出。新论文的页数、设计层次、图表与实验问题数量由新材料和用户要求决定。没有用户另行要求时，保持参考稿的干净页面风格和无讲稿备注；来源映射留在工作记录，必要的公开归属按任务要求保留。

## 替换后核对

- 对照原稿的实际渲染，检查尺寸、标题位置、字体层次、重复元素与图文比例，不能只凭“相近配色”声称沿用了模板。
- 替换旧论文题名、作者/会议信息、正文、图像、表格、超链接、隐藏页和备注中的旧内容；重复出现的模板装饰与标识不误删。
- 新论文的图表与解释必须有自己的来源；默认模板中的示例表格和机制不能充当证据。
- 渲染检查所有新页面；用结构检查器查旧文字残留、备注、页数等适用项。模板选择正确不等于生成内容或排版已合格。
